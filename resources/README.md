These are Cordova resources. Android uses adaptive vector icons, a monochrome
themed icon, and the platform splash screen API. The legacy PNG files remain as
fallback launcher icons for Android 7.0 and 7.1.

Cordova reference documentation:

- Icons: https://cordova.apache.org/docs/en/latest/config_ref/images.html
- Splash Screens: https://cordova.apache.org/docs/en/latest/core/features/splashscreen/
